# Five-minute demo script

1. Log in and show the dashboard statistics, filters and search.
2. Create a task with priority, deadline, progress and attachment.
3. Open Kanban and change a task state; show calendar with multiple tasks on one day.
4. Open report, export CSV, then show activity log and soft-delete restore.
5. Run the JSON API summary with a Bearer token and show the 201 response for task creation.
6. Show `database_setup.sql`, Eloquent entities, middleware and PHPUnit test.
7. Finish with GitHub Actions workflow, issue template, Docker compose and the database backup script.
8. Show `storage/cache` after loading the dashboard, `job_queue` after running the reminder script, and `storage/logs` after a handled error.
