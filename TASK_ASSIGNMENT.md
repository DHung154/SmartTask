# Team workflow

Create one GitHub Issue for every feature or bug. Assign one owner, add an
acceptance checklist, then reference the issue from the pull request.

| Area | Suggested owner | Evidence |
| --- | --- | --- |
| Database and migrations | Member A | SQL migrations and backup |
| MVC, auth and security | Member B | controllers, CSRF, middleware |
| UI, reports and Kanban | Member C | responsive browser demo |
| API, tests and deployment | Member D | API.md, PHPUnit, CI, Docker |
